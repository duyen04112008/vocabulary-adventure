# The Sunday Edit

Blog tĩnh bằng HTML, CSS và JavaScript thuần — thiết kế responsive, có chế độ sáng/tối, tìm kiếm và lọc bài viết theo chủ đề.

## Chạy thử

Mở `index.html` trong trình duyệt. Không cần cài đặt thư viện hay build tool.

## Tệp chính

- `index.html` — cấu trúc trang blog và nội dung mẫu.
- `styles.css` — giao diện responsive và dark/light mode.
- `script.js` — lọc/tìm bài viết, menu di động, lưu lựa chọn giao diện và xử lý form đăng ký mẫu.

Form đăng ký hiện là giao diện demo phía trình duyệt; cần kết nối dịch vụ email hoặc backend để lưu đăng ký thực tế.
